# Security Policy

## Supported Versions

Only the latest release of `wencis` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `wencis` seriously. If you find a security vulnerability, please do **not** open a public issue. Instead, report it privately.

Please report security vulnerabilities by emailing the maintainers at **security@varsen.tech**.

When reporting, please include:
1. A descriptive title and summary of the vulnerability.
2. Step-by-step instructions or a proof of concept (PoC) to reproduce the issue.
3. The potential impact of the vulnerability.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a security fix and disclosure timeline.
